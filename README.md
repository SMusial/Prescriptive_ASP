# Dynamic ASP Allocation Optimizer

Telco Field Services Prescriptive Analytics Demo.

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What It Does

Recommends how to split field-service task volumes across ASPs for Urban, Mountain, and Climb profiles using:

- **Business Scorecard** — multi-criteria ASP comparison
- **Data Confidence Layer** — decisions despite imperfect data
- **Causal Intelligence Layer** — why raw KPIs can mislead
- **Allocation Engine** — constrained optimal task split
- **Management Simulator** — scenarios and dynamic rebalancing

## Target Audience

Business executives, operations managers, contract managers, safety managers, product managers, analytics teams.

## Demo Duration

45 minutes guided walkthrough.
